# FJ Production Website

Premium responsive skincare e-commerce website with WhatsApp-only ordering.

🌐 **Live website:** https://xxnxcc0-byte.github.io/FJ-production-2223/

Open `index.html` or serve the folder with a static web server.

No online payment gateway is included. All order buttons open WhatsApp for 0333 4105708.

## Structure

- `index.html` — home page (hero, categories, shop, gallery, about, contact)
- `product.html` — product detail page
- `admin.html` — simple local product manager
- `assets/products/` — owner-provided product images
- `assets/brand-hero-banner.jpg` — premium hero banner
- `WEBSITE-SPEC-WITH-IMAGES.md` — complete build spec with all image names
